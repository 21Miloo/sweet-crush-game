# Sweet Crush

Desafío 1 de Informática II, Universidad de Antioquia, 2026-2.

Juego de combinaciones hecho en C++. El tablero se guarda como una secuencia de
bits, 3 bits por cada casilla, usando operadores a nivel de bits y memoria
dinámica.

## Cómo correrlo

Abrir el `CMakeLists.txt` en Qt Creator, compilar y ejecutar.

Pide las dimensiones del tablero y luego sale el menú con las opciones.
